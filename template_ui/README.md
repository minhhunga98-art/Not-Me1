# Vertix Spatial Glassmorphism Dashboard V2 + SideBar V5

Gói mã nguồn UI/UX kính mờ không gian (visionOS Spatial Glassmorphism) tối ưu để tích hợp trực tiếp vào **Google Antigravity IDE** hoặc dự án Web/React/Tailwind.

## Cấu trúc thư mục
- `index.html`: Giao diện hoàn chỉnh (HTML5 + Tailwind CSS + Lucide Icons + Vanilla JS) chạy trực tiếp không cần build step.
- `glass-tokens.css`: Bộ biến CSS và class chuẩn hóa cho 3 tầng kính mờ (`spatial-window`, `glass-card`, `glass-sidebar`) để tái sử dụng trong dự án Antigravity.

## Tính năng chính
1. **Glassy SideBar V5 (Click-to-Hold / Pin):** Click vào sidebar hoặc nút `<` / `>` để ghim cố định hoặc thu gọn thành thanh rail; hỗ trợ hover peek và thanh chọn viên thuốc khúc xạ trượt mượt.
2. **Spatial Glass Window V2:** Cửa sổ kính mờ độ trong suốt cao xuyên thấu không gian nền, đi kèm 4 thẻ KPI Bento, biểu đồ dòng tiền SVG, biểu đồ tròn danh mục và dock điều hướng dưới.
3. **Optical Glass Controls:** Nút tinh chỉnh trực tiếp độ trong suốt (`Opacity`), độ mờ (`Backdrop Blur`), cảnh nền (`Warm / Studio / Sunset`) và chế độ `Night mode`.
